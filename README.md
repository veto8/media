# media
Media Manipulation with command line tools

## Run

`./ask.sh` opens the task menu:

| ID | Task |
|----|------|
| 1 | Get audio from YouTube (yt-dlp) |
| 2 | Add MP3 to MP4 (ffmpeg) |
| 3 | Loop MP4 video (ffmpeg) |
| 4 | Trim audio, m4a to mp3 (ffmpeg + sox) |

Each task asks for its inputs, with the old hardcoded values as defaults.
Requires `yt-dlp`, `ffmpeg` and `sox` installed.
